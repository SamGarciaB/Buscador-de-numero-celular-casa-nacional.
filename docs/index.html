La versión completa (PHP + MySQL) puede consultar una base local construida con registros públicos de asignación de numeración del sistema oficial del IFT. Con una fuente real y vigente, puede mostrar el concesionario asignatario, área geográfica o localidad, entidad y modalidad, según los campos disponibles. Para reflejar información actualizada hace falta importar y mantener al día esa base. La asignación de un rango no garantiza quién presta actualmente el servicio a cada línea, por ejemplo, debido a la portabilidad.

Esta demo pública no se conecta al IFT ni a una base real: solo muestra el rango y los resultados ficticios de ejemplo.
